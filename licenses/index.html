Criterio de publicación

NeuroNova Apps no atribuye licencias por suposición. Las entradas específicas se incorporarán únicamente después de revisar dependencias reales, archivos LICENSE y NOTICE, APIs, recursos de terceros, traducciones, bases externas y contenidos sujetos a licencia.

Estado: esta página establece la infraestructura común. Las atribuciones por aplicación se añadirán cuando la auditoría del repositorio correspondiente confirme qué debe publicarse.

Sudolux

El repositorio web usa Playwright y axe-core como dependencias de desarrollo para pruebas. Antes de crear una página de licencias de la app Android se revisarán las dependencias distribuidas realmente con la aplicación.
