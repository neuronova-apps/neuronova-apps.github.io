Primeros pasos

Guía de Quiz Bible para principiantes

El MVP actual es pequeño a propósito: seis preguntas revisadas, una respuesta por pregunta, explicación, referencia bíblica, puntuación y progreso local. Esta guía explica el recorrido completo.

Primeros pasosMVP webLectura estimada: 5 min

Antes de empezar

No necesitas crear una cuenta. El banco se carga desde el propio sitio y el progreso se conserva únicamente en el navegador mediante almacenamiento local. No hay ranking ni sincronización entre dispositivos.

El recorrido del quiz

  1. Lee el enunciado. Cada pregunta indica también una categoría y dificultad inicial.
  2. Elige una opción. Solo una respuesta se considera correcta dentro del banco aprobado.
  3. Comprueba. La respuesta queda registrada y ya no puede puntuarse una segunda vez en ese recorrido.
  4. Lee el contexto. Revisa la explicación y la referencia bíblica mostradas después de comprobar.
  5. Avanza. La posición y respuestas se guardan localmente para continuar tras una recarga.

Qué significa la puntuación

La puntuación muestra cuántas respuestas del banco actual coinciden con la opción correcta revisada. Se recalcula desde las respuestas almacenadas; no se guarda como un número independiente.

Cómo usarlo con teclado

Dentro del grupo de respuestas puedes usar las flechas para recorrer los radios y la barra espaciadora para seleccionar. Tab permite entrar o salir del grupo y llegar a los botones. Al avanzar, el foco se coloca en el nuevo enunciado para facilitar la continuidad de lectura.

Qué ocurre al recargar

Quiz Bible intenta restaurar un estado local válido. Si encuentra respuestas o identificadores incompatibles con el banco actual, normaliza o descarta esos datos. Si el almacenamiento del navegador no está disponible, el quiz sigue funcionando durante esa sesión.

Cómo comenzar de cero

El botón Reiniciar progreso elimina la clave local del quiz y devuelve el recorrido a la primera pregunta. Esto resulta útil cuando quieres repetir el banco como una nueva práctica.

Privacidad: el progreso actual no se sincroniza con una cuenta ni se envía a una base de datos propia de Quiz Bible.
