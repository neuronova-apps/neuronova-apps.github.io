Crucilux · Privacidad

Política de privacidad

Crucilux está diseñado como una aplicación web sencilla que funciona directamente en el navegador.

Datos y almacenamiento

La versión actual no requiere crear una cuenta, no utiliza una base de datos remota para el progreso y no incorpora publicidad ni sistemas propios de seguimiento.

Para permitir que una persona continúe cualquiera de los tres retos después de recargar, Crucilux conserva localmente mediante localStorage el reto seleccionado y, para cada desafío, las letras introducidas en las casillas, las palabras ya resueltas, la pista activa, la casilla seleccionada y la mejor marca alcanzada. La estructura también incluye una versión interna del formato guardado.

Estos datos permanecen en el navegador y no se envían a una base de datos de Crucilux. Si el almacenamiento local no está disponible o no puede utilizarse, los retos continúan funcionando durante la sesión sin persistencia.

Compatibilidad del progreso

Crucilux mantiene compatibilidad con formatos locales anteriores. El progreso de las primeras versiones se asigna al reto Palabras cotidianas. Los estados creados antes de guardar letras parciales siguen siendo válidos: las letras de cualquier palabra ya resuelta se reconstruyen automáticamente dentro del tablero.

Retención y reinicio

El botón Reiniciar reto borra las letras parciales y las palabras resueltas únicamente del desafío visible y vuelve a su primera pista, pero mantiene la mejor marca histórica de ese reto. Cambiar de categoría no elimina el progreso guardado de los demás desafíos.

El control Borrar palabra elimina únicamente las letras editables de la palabra activa; las casillas compartidas que ya quedaron fijadas por una palabra resuelta se conservan.

La persona usuaria también puede eliminar todos estos datos borrando el almacenamiento del sitio desde la configuración de su navegador.

Información personal

Crucilux no solicita nombre, correo electrónico, ubicación, contactos ni otros datos personales para utilizar sus funciones actuales.

Servicios externos

El sitio se publica mediante GitHub Pages. El acceso al repositorio de GitHub o a otros enlaces externos queda sujeto a las políticas de esos servicios.

Cambios futuros

Si futuras versiones incorporan cuentas, sincronización en línea, analítica, servicios externos o nuevas formas de tratamiento de datos, esta política se actualizará antes de habilitar esas funciones.
