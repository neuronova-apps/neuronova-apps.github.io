Política de privacidad de Sudolux

Esta política explica cómo Sudolux maneja la información necesaria para funcionar en su aplicación Android y, cuando corresponda, en su versión web.

Aplicación: Sudolux Responsable: NeuroNova Apps · Gabriel Berrospi Actualizada: 5 de septiembre de 2026
Resumen de privacidad: Sudolux no requiere una cuenta, no integra publicidad ni servicios de analítica o seguimiento, Crashlytics, telemetría remota, compras ni Billing en la versión Android Beta 1 auditada. El progreso y la configuración se procesan principalmente de forma local.

Alcance

Esta política cubre la aplicación Sudolux para Android y la versión web de Sudolux cuando sea utilizada. Ambas ofrecen una experiencia de Sudoku, pero emplean mecanismos técnicos distintos para guardar el estado local; esas diferencias se describen en las secciones correspondientes.

Datos locales en Android

La aplicación Android almacena localmente la información necesaria para ofrecer sus funciones, conservar las preferencias y permitir la continuidad del juego. Esto puede incluir XP y progreso, medallas, estadísticas, desbloqueos, configuración, tema, estilo de tablero, partidas completadas y una partida activa.

El estado de una partida puede incluir el tablero y su solución, valores introducidos, notas, errores, pistas utilizadas, nivel de dificultad, modalidad y otros datos técnicos del juego. Sudolux utiliza identificadores aleatorios para distinguir partidas y evitar procesarlas más de una vez. Son identificadores internos del juego y no son identificadores de cuenta, publicidad o dispositivo.

Estos datos se utilizan para ejecutar el juego, reanudar una partida, calcular el progreso y aplicar las preferencias seleccionadas. Sudolux no dispone de un servidor propio para sincronizar este progreso.

Almacenamiento privado de la aplicación

El progreso, la configuración y la partida se guardan mediante almacenamiento privado de preferencias y estado proporcionado por Android. Otras aplicaciones ordinarias no reciben acceso directo a ese almacenamiento mediante Sudolux.

Datos personales y cuentas

La versión Android auditada de Sudolux no solicita nombre, correo electrónico para utilizar la aplicación, número telefónico, contactos, ubicación, fotografías, audio, documentos personales, información financiera, datos de salud ni credenciales de cuenta.

Sudolux no requiere crear una cuenta ni iniciar sesión en la versión actual. Por ello, no existe una cuenta de Sudolux que el usuario deba solicitar eliminar. Esto es independiente de las opciones disponibles para eliminar los datos locales de la aplicación.

Permisos y conectividad en Android

Actualmente, la versión Android auditada de Sudolux no solicita el permiso de Internet ni permisos sensibles para su funcionamiento principal. La aplicación no establece conexiones automáticas para enviar a NeuroNova Apps el progreso de juego o información personal.

Los enlaces externos sólo se abren cuando el usuario selecciona voluntariamente la opción correspondiente y Android entrega la dirección al navegador externo disponible en el dispositivo.

Copia de seguridad y transferencia de Android

Android puede incluir determinados datos locales de Sudolux —como progreso, configuración y partida activa— en mecanismos de copia de seguridad, restauración o transferencia entre dispositivos cuando esas funciones estén disponibles y habilitadas en el dispositivo, la cuenta o la configuración del usuario.

Estos mecanismos son proporcionados y administrados por Android o por los servicios del sistema correspondientes; no constituyen un servidor propio de NeuroNova Apps. Su disponibilidad, frecuencia, conservación y resultado dependen del sistema y no están garantizados por Sudolux.

Versión web

Cuando se utiliza la versión web, Sudolux puede guardar localmente en el navegador el estado necesario para continuar una partida, como el tablero generado, su solución, valores introducidos, candidatos o notas, intentos incorrectos, casilla seleccionada y modo Notas. Este guardado puede utilizar localStorage.

El almacenamiento local del navegador es distinto del almacenamiento privado de la aplicación Android. La información web local se utiliza para restaurar el estado del juego en el mismo navegador y no requiere una base de datos personal remota de Sudolux.

Recogida, compartición y venta

Sudolux no integra actualmente mecanismos propios ni SDK de publicidad, analítica o telemetría que transmitan automáticamente a NeuroNova Apps el progreso o información personal del usuario. La versión Android Beta 1 auditada tampoco integra Crashlytics, Billing ni un backend de cuentas.

Sudolux no comparte esos datos con anunciantes y no vende datos personales. Esta descripción se refiere al funcionamiento propio de Sudolux y no pretende abarcar el tratamiento independiente realizado por Android, el navegador, GitHub Pages u otros sitios o servicios externos.

Retención y eliminación

Android

Los datos locales permanecen en el almacenamiento de Sudolux mientras existan los datos de la aplicación. El usuario puede eliminarlos mediante las funciones de Android para borrar los datos de la aplicación o desinstalando Sudolux.

La opción de restablecer configuración dentro de Sudolux restablece las preferencias de configuración, pero no constituye un borrado completo del progreso. Una copia de seguridad administrada por Android puede tener un ciclo de retención independiente del almacenamiento local del dispositivo; NeuroNova Apps no puede eliminar remotamente una copia administrada por el sistema.

Web

La versión web conserva localmente la información de una partida según el funcionamiento de la experiencia y el almacenamiento del navegador. El usuario puede eliminarla borrando los datos del sitio desde la configuración de su navegador.

Servicios de terceros y enlaces externos

Sudolux incluye enlaces voluntarios hacia páginas de privacidad, términos, licencias, soporte y el sitio de NeuroNova Apps. En Android, esos enlaces se entregan al navegador externo únicamente después de la acción del usuario.

Una vez abierta una página externa, su tratamiento de información también se rige por las políticas y condiciones del navegador, del sistema y del sitio correspondiente. Sudolux no controla el funcionamiento independiente de esos servicios externos.

Seguridad

Sudolux utiliza el almacenamiento privado proporcionado por Android para sus datos locales. En la versión web, el almacenamiento local es administrado por el navegador. NeuroNova Apps procura mantener medidas técnicas razonables acordes con la arquitectura de la aplicación, aunque ningún sistema puede garantizar seguridad absoluta.

Menores y cambios en la política

Sudolux no está diseñado para solicitar deliberadamente información personal de menores en las versiones auditadas.

Esta política podrá actualizarse cuando cambien las funciones, el tratamiento de datos, los servicios integrados o los requisitos aplicables. La fecha visible al inicio permite identificar la versión vigente.
