Política de privacidad

Esta política centraliza la información ya publicada para Sudolux y describe el tratamiento verificado en la versión web disponible en su repositorio público.

Aplicación: SudoluxResponsable: NeuroNova Apps · Gabriel BerrospiCentralizada: 24 de agosto de 2026
Alcance actual: el repositorio conectado de Sudolux contiene la versión web y su política vigente. Antes de utilizar esta ruta como política de una versión Android en Google Play debe contrastarse nuevamente con el código Android real, sus SDK, permisos, publicidad, Firebase, APIs, autenticación y demás servicios.

Datos y acceso

La versión web actualmente publicada puede utilizarse sin crear una cuenta y sin proporcionar nombre, correo electrónico, teléfono u otros datos identificativos para acceder a la experiencia básica.

Cuando existe una partida web en progreso, Sudolux almacena localmente en el navegador el tablero generado, su solución, los valores introducidos, candidatos o notas, casillas con intentos incorrectos, la casilla seleccionada y el estado del modo Notas. Este guardado utiliza localStorage y permite continuar la partida después de recargar.

Estos datos permanecen en el dispositivo o navegador y no requieren una base de datos personal remota para la demo web verificada.

Uso de la información

La información local de la partida se utiliza para restaurar el estado de la demo web y continuar el juego en el mismo navegador. La política existente no declara uso de estos datos para perfiles publicitarios, analítica de comportamiento ni venta de información personal.

Compartición

En la configuración web verificada, el estado local de la partida no se envía a un servidor de Sudolux. Los enlaces externos se rigen por las políticas del servicio de destino.

Seguridad

La versión web valida la estructura del tablero, la solución, las pistas fijas y los valores almacenados antes de restaurar una partida. Si los datos locales no son coherentes, se ignoran y se genera una nueva variante.

Retención y eliminación

La demo web conserva localmente la partida mientras exista progreso sin completar. Al dejar el tablero sin valores ni notas o al completar correctamente la partida, el guardado se elimina. También puede eliminarse borrando los datos del sitio desde la configuración del navegador.

La versión web verificada no declara una base de datos remota de cuentas personales.

Servicios de terceros

La política web vigente no declara redes publicitarias ni servicios de seguimiento necesarios para el funcionamiento básico. Cualquier incorporación futura deberá revisarse y declararse antes de utilizar esta política para una nueva versión.

Menores y cambios

Sudolux no está diseñado para solicitar deliberadamente información personal de menores en la versión web verificada. Esta política se actualizará cuando cambien las funciones, servicios o requisitos aplicables.

Contacto

Para consultas sobre privacidad: neuronova.apps@gmail.com.
