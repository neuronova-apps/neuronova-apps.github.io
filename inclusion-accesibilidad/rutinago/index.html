RutinaGo

Apoyo visual para organizar rutinas, actividades y pasos cotidianos, favoreciendo la participación y la autonomía.

Acerca de RutinaGo

Aplicación Android gratuita y sin fines de lucro, orientada al acompañamiento de familias que necesitan apoyos visuales para estructurar actividades y rutinas.

Disponibilidad y recursos

Este espacio ofrece información sobre la aplicación. No contiene una versión web interactiva ni reemplaza el proyecto Android.
