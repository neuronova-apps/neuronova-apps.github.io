Eliminación de datos y cuentas

Procedimiento central para solicitudes de eliminación relacionadas con las aplicaciones de NeuroNova Apps, incluidas las versiones Android y Facebook Instant Games.

Actualización: 28 de agosto de 2026Contacto: neuronova.apps@gmail.com

Facebook Instant Games

Si utiliza Sudolux, Crucilux o Sopalux mediante Facebook Instant Games y desea solicitar la eliminación de datos asociados al juego, puede enviar una solicitud a NeuroNova Apps indicando claramente el nombre del juego y que la solicitud corresponde a Facebook Instant Games.

Datos para identificar la solicitud: indique el juego, la plataforma "Facebook Instant Games" y, si está disponible, el identificador de jugador o la información mínima necesaria para localizar los datos. No envíe contraseñas ni datos sensibles.
Solicitar eliminación de datos de Facebook

Tras recibir una solicitud válida, se revisarán los datos asociados que estén bajo control de NeuroNova Apps y se eliminarán cuando corresponda, salvo aquellos que deban conservarse por obligaciones legales o técnicas aplicables.

Android y otras versiones

Las versiones Android mantienen políticas independientes por aplicación dentro del centro de privacidad. Cuando una aplicación permita crear una cuenta, el procedimiento de eliminación se ajustará a la funcionalidad real y a los requisitos aplicables de Google Play.

Separación por plataforma: una solicitud de Facebook Instant Games no se presume automáticamente aplicable a la versión Android, ni una solicitud Android se extiende a Facebook, salvo que el usuario lo indique expresamente.
