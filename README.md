# Neuronova Apps

Neuronova Apps es una iniciativa personal e independiente orientada al desarrollo progresivo de aplicaciones web con propósitos diversos: accesibilidad, aprendizaje, bienestar y entretenimiento.

La plataforma funciona como una matriz principal que reúne proyectos independientes bajo una misma identidad. Cada aplicación puede evolucionar por separado, manteniendo un acceso centralizado desde la web principal de Neuronova Apps.

## Iniciativa

El proyecto nace como una iniciativa personal de Gabriel Berrospi, con el propósito de explorar, diseñar y desarrollar soluciones digitales útiles, sencillas y accesibles. Neuronova Apps no corresponde a una institución ni representa oficialmente a una entidad pública o privada.

## Propósito

El propósito de Neuronova Apps es crear un ecosistema de aplicaciones web que pueda crecer de manera gradual, priorizando una experiencia clara para el usuario, compatibilidad con distintos dispositivos y criterios de accesibilidad cuando correspondan.

## Alcance

En su etapa inicial, el ecosistema está conformado por tres aplicaciones:

- **Brailux:** propuesta orientada al conocimiento, aprendizaje y difusión del sistema Braille.
- **Motiva:** aplicación de frases motivacionales y reflexivas para acompañar distintos momentos del día.
- **Sudolux:** aplicación de Sudoku orientada al entretenimiento y al ejercicio de la lógica.

La estructura está preparada para incorporar nuevos proyectos en el futuro sin modificar la independencia de las aplicaciones existentes.

## Desarrollo

Neuronova Apps se encuentra en desarrollo continuo. Las funciones, interfaces, contenidos y características de cada aplicación pueden cambiar durante las etapas de diseño, prueba y mejora.

Cada aplicación cuenta con su propio repositorio, lo que permite mantener un desarrollo modular y realizar actualizaciones de manera independiente.
